# docker/certs — 追加で信頼する証明書

HTTPS の通信を検査するソフト（ウイルス対策ソフトの「Web 保護」「HTTPS スキャン」、会社・学校のプロキシなど）がある環境では、アプリの組み立て時に PyPI からのダウンロードが `CERTIFICATE_VERIFY_FAILED` で失敗します。

このフォルダに置いた `*.crt`（PEM 形式。複数の証明書をまとめたファイルも可）は、アプリと Python ワーカーのイメージを組み立てるときに追加で信頼されます。

- 起動用ファイル（`start.bat` / `start.command`）は、証明書エラーを検出すると、確認のうえ **この PC が信頼している証明書** をここに書き出して組み立て直します（`host-trusted-roots.crt`）。
- ここに置いた証明書は Git の管理対象外です（`.gitignore`）。不要になったら削除し、もう一度起動して組み立て直してください。
